# 📝 To-Do App

A simple, clean, and responsive To-Do List web application built with **HTML**, **CSS**, and **JavaScript**.  
It allows users to add, complete, and delete tasks in an elegant interface.

---

## 🚀 Features

- ➕ Add new tasks easily  
- ✅ Mark tasks as completed by clicking on them  
- ❌ Delete tasks individually  
- ⚡ Instant updates without reloading the page  
- 💅 Minimal and responsive design

---

## 🧩 Technologies Used

- **HTML5** – Structure of the app  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Dynamic behavior and task management
